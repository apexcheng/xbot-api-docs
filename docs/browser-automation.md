# 影刀浏览器自动化指南：xbot 网页操作与 AI Agent 开发入口

本文帮助开发者快速定位影刀 xbot 浏览器自动化资料，适用于网页打开、元素查找、点击、输入、滚动、下载、Cookie、网络监听和 iframe 等场景。

完整 API 细节请查看：

- [xbot 浏览器操作文档](../xbot-api-docs/docs/browser.md)
- [iframe2 扩展指令说明](../xbot-api-docs/docs/iframe2-extension.md)
- [影刀增强工具](../xbot-api-docs/docs/extensions/xbot-enhance-tools.md)

## 常见浏览器自动化任务

影刀编码版常见网页自动化需求包括：

- 打开指定 URL
- 切换或管理浏览器页面
- 根据元素库对象、XPath 或页面结构查找元素
- 点击按钮、链接和菜单
- 输入文本、选择选项和提交表单
- 获取元素文本、属性和状态
- 页面滚动与列表加载
- 等待页面或元素出现
- 文件上传和下载
- 读取或写入 Cookie
- 监听网络请求
- 操作 iframe / frame 内元素
- 处理登录状态、弹窗和页面异常

## 开发前需要收集的信息

让 AI Agent 开发网页自动化前，最好提供：

1. 目标 URL
2. 当前浏览器和登录状态
3. 页面操作步骤
4. 目标元素的文字、属性或元素库名称
5. 页面是否包含 iframe
6. 是否存在懒加载、分页或无限滚动
7. 下载文件的预期名称和目录
8. 成功后的页面状态或数据结果
9. 失败时需要重试、跳过还是终止

## 推荐调查顺序

```text
确认真实操作流程
    ↓
检查现有影刀元素库和代码
    ↓
确定页面是否含 iframe
    ↓
选择元素定位方式
    ↓
实现等待、点击、输入和读取
    ↓
处理滚动、分页、下载或网络请求
    ↓
在真实登录环境验证
```

## 元素定位原则

### 优先复用现有元素库

真实项目中已经存在并稳定使用的元素库对象，通常比重新猜测选择器更可靠。

### 不要只依赖随机 class

现代网页经常生成带随机后缀的 class。遇到这类页面时，应结合：

- 稳定的文本
- 稳定属性
- 父子结构
- 元素语义
- 已有元素库配置
- 可验证的 XPath 或其他定位方式

### 页面结构必须以实际 DOM 为准

按钮文字相同不代表元素结构相同。AI Agent 应先检查实际页面或现有代码，再决定定位方式。

### iframe 需要单独确认

普通页面元素和 iframe 内元素的查找方式可能不同。页面包含 frame 时，应查阅 [`iframe2-extension.md`](../xbot-api-docs/docs/iframe2-extension.md)，不要把普通页面查找逻辑直接套用。

## 等待比固定休眠更重要

网页自动化常见失败原因不是代码完全错误，而是：

- 页面尚未加载完成
- 元素尚未出现
- 元素存在但不可点击
- 异步请求尚未返回
- 下载尚未完成
- 页面滚动后内容仍在加载

应优先使用文档中已有的等待能力或增强工具，而不是无条件增加很长的固定休眠。

相关入口：

- [浏览器文档](../xbot-api-docs/docs/browser.md)
- [影刀增强工具](../xbot-api-docs/docs/extensions/xbot-enhance-tools.md)

## 滚动和懒加载

处理评价列表、商品列表、订单列表等懒加载页面时，需要确认：

- 实际滚动的是整个页面还是内部容器
- 容器选择器是否稳定
- 每次滚动后是否有新增内容
- 是否存在“查看更多”按钮
- 是否达到页面底部
- 是否有最大页数或最大采集条数
- 数据是否需要去重

不要只执行滚轮动作而不检查数据量是否增长。

## 下载任务

下载自动化需要同时确认：

- 点击下载前的页面状态
- 下载是否由按钮、链接或网络请求触发
- 默认下载目录
- 文件名是否动态变化
- 下载完成的判定方式
- 文件是否需要重命名、解压或继续处理

可查看：

- [浏览器操作文档](../xbot-api-docs/docs/browser.md)
- [压缩解压文档](../xbot-api-docs/docs/xzip.md)
- [影刀增强工具中的下载等待](../xbot-api-docs/docs/extensions/xbot-enhance-tools.md)

## 登录、验证码和风控

自动化运行结果可能受以下因素影响：

- 账号未登录
- Cookie 过期
- 浏览器用户资料不同
- 页面出现验证码
- 设备或网络触发风控
- 页面返回简化版或异常版结构

遇到这些情况时，不应继续把错误归因于选择器。先记录页面实际状态，再决定是否需要人工登录、复用浏览器资料或停止任务。

## 网络请求监听

当页面数据由接口加载、DOM 中不易获取，或需要确认真实请求参数时，可以查看浏览器文档中的网络监听能力。

适合场景：

- 页面列表由接口分页加载
- 下载链接动态生成
- 需要确认请求参数或返回结构
- DOM 只展示部分数据

但网络请求方案也应经过实际验证，不能仅根据浏览器开发者工具中的接口推测影刀代码一定可直接调用。

```text
请在真实影刀项目中排查并实现网页自动化。

目标页面：...
真实项目目录：...
知识库目录：C:\Users\Administrator\Desktop\影刀xAI开发指南

操作流程：
1. 打开 ...
2. 点击 ...
3. 等待 ...
4. 读取 ...

要求：
- 先读取 AGENTS.md，并检查项目现有元素库和浏览器代码。
- 仅当新增或无法确认 xbot API、市场指令、页面行为时，再按 llms.txt 定位 browser.md 等相关文档。
- 判断目标元素是否位于 iframe。
- 不要依赖明显随机的 class。
- 使用可验证的等待条件，不要只增加固定休眠。
```

## 常见故障定位

### 找不到元素

检查：

- 页面是否加载完成
- 是否进入了错误页面
- 是否需要登录
- 元素是否在 iframe
- 定位表达式是否依赖随机 class
- 页面是否因风控返回不同结构

### 点击无反应

检查：

- 元素是否被遮挡
- 元素是否可点击
- 是否需要先滚动到可视区域
- 是否点到了父容器而不是实际按钮
- 点击后是否需要等待异步请求

### 滚动后没有新增数据

检查：

- 滚动对象是否正确
- 是否存在内部滚动容器
- 是否需要点击“查看更多”
- 是否已经到底
- 是否被登录、验证码或网络异常阻断

### 下载文件不存在

检查：

- 下载动作是否实际触发
- 下载目录是否正确
- 文件名是否变化
- 下载是否尚未完成
- 页面是否返回了错误文件或提示页
