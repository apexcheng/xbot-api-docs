# xbot API 文档维护规则

本目录只保存影刀 xbot API 和市场指令的可核验事实。通用开发规则以仓库根目录 `../AGENTS.md` 为准，业务代码应在真实影刀项目中修改。

## 内容边界

- 一个事实只保留在一篇最相关的文档中；其他位置使用链接。
- 只记录 API 签名、参数、返回值、版本差异、最小调用、高频真实故障，以及与该 API 直接相关的安全边界和高频误用约束。
- 不在这里复制跨领域 Agent 工作流、通用代码风格、通用 Python 教程、项目架构或特定业务流程；这类稳定规则统一由根 `AGENTS.md` 维护。
- 示例遵守根 `AGENTS.md` 的“API 与知识库”规则。写入、发送消息、下载及其他有实际副作用的调用只保留签名、前置条件和最小调用形态，使用标注“非执行调用说明（不可直接运行）”的 `text` 代码块或正文，不提供可误运行的完整脚本。只读 API Python 片段注明前置对象和适用条件，不声称可独立运行。

## 证据

- 优先依据当前安装版本源码或运行验证，其次才是稳定项目代码和官方说明。
- 文档写明证据版本或核验方式，不固定某台电脑上的绝对安装路径。
- 无法确认的参数、返回值或页面行为必须标注“需运行验证”，不得写成稳定事实。
- 市场指令先按 `docs/extension-instructions.md` 确认包装入口与真实实现，不从界面中文选项猜编码参数。

不得提交市场指令内部源码、反编译内容、账号、令牌、Cookie 或其他敏感信息。
