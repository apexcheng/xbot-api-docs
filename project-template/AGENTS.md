# AGENTS.md

本文件用于真实影刀 xbot / 编码版项目。

核心原则：**最小改动、过程清楚、不猜 API、按风险验证。**

## 开始任务

1. 用户当前需求、项目已有业务逻辑、参数约定和数据口径优先。
2. 只改与需求直接相关的内容，不做无关重构、格式化或结构调整。
3. 目标清楚时直接执行；复杂任务只做“简短计划 → 执行 → 验证”。
4. 知识库路径由用户或项目提供。路径缺失时请求正确位置，不猜固定路径。
5. 先读当前项目代码；只有新增或无法确认 xbot API、市场指令或页面行为时，才按知识库的 `llms.txt` 查对应页面。
6. 新建或补全项目时读取知识库 `docs/base-project-skeleton.md`；多个必需数据源写入同一工作簿时读取 `docs/multi-source-report-safety.md`。

## 实现方式

1. 自动化和数据处理默认采用自上而下的过程式主流程，让读取、判断、操作、写回、保存和通知顺序直接可见。
2. 只有明显复用、形成独立业务边界或显著降低理解成本时才抽取函数、模块或类。
3. 不新增无必要的 Service、Manager、Context、Factory、多层 wrapper、动态调度或大型配置系统。
4. 不为未来需求预留未使用参数、分支、Hook 或扩展点。
5. 不根据通用 Python 经验或旧项目记忆猜 API、XPath、页面字段、命令和市场指令参数。
6. 必须依赖真实影刀、WPS、浏览器或页面才能确认的行为，标记“需运行验证”。
7. 影刀日志使用 xbot 日志能力，不使用 Python 标准 `logging`；网页业务默认使用 `xbot.web`，除非用户明确要求接口方式或项目已有稳定接口实现。
8. Code 流入口通常为 `main(args)`；已知参数名时严格使用已有名称，输入不确定时只在入口归一化一次。
9. 能用元素或选择器时不优先坐标点击；新增第三方依赖需要用户明确允许或项目已在使用。
10. 读取旧版影刀可视化编排项目时，使用 `.agents/skills/xbot-visual-flow-reader/SKILL.md`；纯 Python 任务不触发。

## 验证与同步

1. 按风险做最小必要验证；小改只检查相关路径，高风险写入先确认范围与回退方式。
2. `shadowbot_sync_tool.py` 与 `package.json` 位于项目根目录。
3. 新增 `.py` 文件后默认运行 `python shadowbot_sync_tool.py`，用户明确要求暂不同步时除外。
4. 用户要求“同步影刀”或同类操作时，也执行该命令，即使只修改已有 `.py` 文件。
5. 同步不是 Git 提交、推送或普通文件复制。
6. 同步成功不等于已在影刀编辑器中运行验证。
7. 同步脚本自动扫描 Python 文件，不接收文件列表或 `prepare` 子命令。
8. 需要完整错误堆栈时使用 `traceback.format_exc()`；通用排错见知识库 `docs/troubleshooting.md`。

完成后简短说明修改内容、验证与同步情况，以及仍需运行验证的事项。未运行测试、同步或影刀编辑器内验证时必须明确说明。
